# UK Road Safety Analysis

## Overview

This project analyzes road traffic accident data from the UK Department for Transport (DfT) STATS19 dataset.

The objective is to identify trends, accident severity patterns, and factors influencing road safety in Great Britain using Exploratory Data Analysis (EDA).

## Dataset

Source: UK Government Road Safety Statistics (STATS19)

The dataset contains information about:

* Road traffic collisions
* Casualties
* Vehicles involved
* Weather conditions
* Road conditions
* Speed limits

## Key Findings

* Accident severity varies significantly across road types.
* Weather and lighting conditions influence accident frequency.
* Traffic patterns reveal peak collision periods.
* Road characteristics contribute to differing risk levels.
